    随笔 · 2025.09.14

    少一点，但别太少

    约 1,300 字 · 5 分钟

    这个博客重做了三次。前两次都停在同一个地方：做得太素，像一份没排版的文档；往上加东西，又很快变成一个模板网站。这篇记下第三次定下来的几条规矩，免得以后又改回去。

    01字

    正文和标题都用上图东观体1。它的字形来自宋刻本，横细竖粗，起笔带一点刀刻的方角。同一套字从标题用到正文，页面就不需要再靠颜色和装饰去区分层级，字号、字重和留白已经够用。

    1上海图书馆发布的字体。这里已用 cn-font-split 切成 156 个子集，浏览器只下载页面上用到的那部分字。字体带竖排标点，可以直接竖排。

    日期、坐标、里程这类数字用等宽字体，排成小字号。它们是数据，不是文字，看上去应该不一样。需要的时候，一段引文也可以竖排：

    天有时，地有气，材有美，工有巧。合此四者，然后可以为良。《考工记》

    02纸和墨

    底色是偏暖的纸白，不是纯白；字是墨色，不是纯黑。全站只有一个强调色，默认是克莱因蓝，只用在两处：地图上的路线，和“你现在读到哪里”的标记。链接平时不变色，悬停时才出现一条细下划线。

    浮在内容上面的东西，比如滚动后的页头、角落里的小控件、点开大图时的背景，用磨砂玻璃：纸色半透明，加一层模糊和很细的颗粒，底下的照片隐约透出来。只有浮着的东西用，平铺在页面上的内容不用。

    03动

    动画只做一件事：告诉你东西从哪里来、到哪里去。从列表点进文章，标题会从原来的位置移到新位置，而不是整页闪白2；读游记的时候，地图上的路线跟着阅读进度往前走。

    2页面切换用浏览器原生的 View Transitions，Astro 内置支持，不需要额外的动画库。

    不做的：图片从四面八方飞进来，滚动时每段文字依次淡入，跟着鼠标走的光晕。这些第一次看觉得新鲜，第三次就烦了。

    04代码

    技术文章里的代码同样用等宽字体，底色比纸深一档，高亮只分三种颜色，不用花哨的主题。

    // src/content.config.ts —— 游记的块：位置由作者指定
const block = z.object({
  type: z.enum(['text', 'single', 'pair', 'strip', 'grid', 'free']),
  writing: z.enum(['horizontal', 'vertical']).optional(),
  y: z.number().min(0).max(1).optional(),   // 横滚时的上下位置
  scale: z.number().optional(),
});

    05不要的东西

    • 渐变背景和发光的按钮
    • 什么都装进一张带阴影的圆角卡片
    • 用 emoji 当图标
    • 首屏一句大口号，下面并排两个按钮

    这些东西本身没有错，只是出现得太多，已经不代表任何人了。留下来的是：细线分隔而不是色块，正文靠左，右边留给注释；图片不加圆角也不加阴影。

    这些规矩大概还会改。但改之前，至少先写清楚为什么。

    冰岛，逆时针

    沿一号公路绕岛一圈。租车公司的人说，逆时针走，把最好的留到最后。我们没问什么是最好的。

    日期
    2025.06.12 — 06.21
    天数
    10
    里程
    2,140 KM
    站点
    8

    落地是晚上十一点，天还亮着。六月的冰岛没有夜，只有一段很长的黄昏，接着又是早晨。

    在超市买了一周的面包和咖啡，第一晚住在港口边上，窗帘很厚。

    北美板块和欧亚板块在这里裂开，每年分开两厘米左右。

    裂缝里的水清得看不出深浅。

    黑沙滩上的风大到站不稳。海里那几根石柱，传说是天亮前没来得及回去的巨人。

    冰块从冰川上断下来，在湖里漂几年，漂到出海口。

    再被浪推回黑沙滩，像被人扔了一地的玻璃。

    东部峡湾。路窄，弯多。镇上只有六百多人，一条彩色的路通向一座浅蓝色的教堂。

    地热区的硫磺味很重。附近的众神瀑布，据说一千年前有人把旧神像扔进了这里，从此改信了新的神。

    北部最大的镇子。红绿灯里的红灯是心形的，等灯的时候不太想走。

    最后一天。凡尔纳让他的主角从这座火山口下去，一直走到地心。

    我们只是在山脚下的海边坐了一个下午。

    全程 2,140 KM 回到雷克雅未克。继续向下滚动，是整段行程。
